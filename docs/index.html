Features

为日常玩家与开服者准备的功能

从登录、装版本到管理模组和开服，常用操作都留在同一个窗口里。

微软正版登录

设备码登录流程，自动读取正版皮肤、经典 / 纤细形态与登录续期，也支持离线模式。

3D 皮肤预览

原生 WPF 3D 渲染，主页头部头像与全身小人支持拖拽旋转、滚轮缩放与行走动画，像素边缘清晰。

版本与加载器

原版 / Fabric / Forge / NeoForge 一键安装，多目录与版本隔离；官方 Maven 不通时自动换镜像重试。

模组与整合包

Modrinth / CurseForge 搜索下载，自动补齐前置；整合包下载后直接解析成游戏列表里的客户端。

指令生成

/give 与 /summon 可视化生成，按版本适配 NBT 与数据组件，物品、生物附带中文名。

开服工具

服务端核心与插件下载、server.properties 可视化配置、后台启动与控制台输出。

界面可定制

白天 / 黑夜主题、玻璃面板浓度、背景图与模糊、各区域透明度、主题色与背景音乐。

简洁版引导器

轻量引导器检测不到 .NET 10 桌面运行时会自动下载安装，随后释放并启动主程序。

网络容错

连接超时、镜像候选、指数退避重试；下载失败时明确提示缺失文件与官方下载页。

Build

从源码构建

需要 Windows 10/11 与 .NET SDK 10。

# 克隆仓库
git clone https://github.com/xianyuhp/MC-Tool-Launcher.git
cd MC-Tool-Launcher

# 编译并运行
dotnet build src\AuroraLauncher\AuroraLauncher.csproj -c Release
dotnet run --project src\AuroraLauncher\AuroraLauncher.csproj

# 发布自包含单文件
dotnet publish src\AuroraLauncher\AuroraLauncher.csproj -c Release -r win-x64 `
  --self-contained true -p:PublishSingleFile=true `
  -p:IncludeNativeLibrariesForSelfExtract=true `
  -p:EnableCompressionInSingleFile=true -p:DebugType=none -o publish
